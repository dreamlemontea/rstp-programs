# Улучшалка и Скачивалка

Подарок от [RSTP Studio](https://rstpstudio.ru) · Сделано в [«Релизной»](https://reliznaya.ru).
Отсюда установленные программы сами берут обновления (кнопка «Обновить»). Версия 1.0.1.

- **Улучшалка** — делает изображения чётче и больше с помощью ИИ, прямо на компьютере.
- **Скачивалка** — видео и звук по ссылке (на основе [yt-dlp](https://github.com/yt-dlp/yt-dlp)).

Нейросети в `Улучшалка/модели`: Real-ESRGAN (BSD-3-Clause, Xintao Wang и др.),
4xNomos8kSC (CC BY 4.0, Philip Hofmann).
